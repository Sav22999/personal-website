# Fucina — scheda Google Play

**Nome:** Fucina
**Descrizione breve (IT):** Impara HTML e CSS a livelli, tra quiz, giochi e certificati.
**Short description (EN):** Learn HTML and CSS level by level, with quizzes, games and certificates.

**Descrizione completa (IT):**
Fucina è il posto in cui il codice si forgia. Ogni corso è una serie di livelli sempre più difficili: teoria breve, domande,
esercizi di codice con anteprima dal vivo. Guadagni XP e Scintille, che puoi spendere in suggerimenti. Sfide del giorno, cinque
giochi a livelli, statistiche, traguardi e un certificato da mostrare e stampare per ogni corso (senza valore legale).

**Full description (EN):**
Fucina is where code is forged. Every course is a series of levels that get harder: short theory, questions, coding exercises with
a live preview. Earn XP and Sparks to spend on hints. Daily challenges, five levelled games, statistics, badges and a certificate
to show and print for every course (no legal value).
